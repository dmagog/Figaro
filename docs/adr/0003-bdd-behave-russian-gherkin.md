# 0003 — BDD на behave с русским Gherkin

- Статус: accepted
- Дата: 2026-05

## Контекст

Реализацию ведём от поведения. Стейкхолдеры (заказчик, исследователь) — русскоязычные; ubiquitous language русский («маршрутный лист», «накладка», «повтор программы»). Проект на Python, в v2 использовался pytest.

## Решение

BDD-фреймворк — **behave**; сценарии на **русском Gherkin** (`# language: ru`). Шаги (Python) — на английском. Фичи живут в `features/`, шаги в `features/steps/`, фикстуры в `features/fixtures/`.

## Последствия

- (+) Сценарии читаемы заказчиком → контракт = приёмочные тесты = living documentation.
- (+) Русский Gherkin совпадает с ubiquitous language.
- (−) behave вне pytest-экосистемы (фикстуры/параметризация иначе, чем у pytest-bdd). Принято осознанно ради «классического» BDD-раннера.
- BDD не заменяет юнит-тесты: алгоритмику покрываем pytest, веб — тонким smoke (пирамида в [08](../08-cross-cutting.md#пирамида-тестов-чтобы-не-гёркинизировать-всё)).
- Связано: [07](../07-bdd.md).
