# 0001 — Server-rendered + HTMX вместо SPA

- Статус: accepted
- Дата: 2026-05

## Контекст

v3 — продукт для зрителя с интерактивом (сборка маршрутного листа, подсказки, показ конфликтов). Команда невелика, бот отложен, нагрузка низкая (~5000 зрителей). Нужен быстрый путь к MVP без раздувания фронтенд-стека.

## Решение

Server-rendered FastAPI + Jinja2 + **HTMX** для частичных обновлений (Alpine.js точечно). Без отдельного SPA.

## Последствия

- (+) Быстрый MVP, один язык/стек, простой деплой, хороший UX для нашего объёма интерактива.
- (+) Меньше дублирования логики между фронтом и бэком.
- (−) Очень богатый клиентский интерактив сделать сложнее, чем в SPA.
- Пересмотреть, если появится потребность в сложном клиентском состоянии — тогда возможен переход на SPA + API (поверхность эндпоинтов уже описана в [05](../05-architecture-and-platform.md#экраны-и-эндпоинты-htmx)).
